# Projeto-Bioinformatica_PG61008

Computational Image Analysis to Support Microplastic Mitigation in Wastewater Treatment Systems

---

## Descrição

Este repositório contém todos os materiais desenvolvidos no âmbito do projeto de
Bioinformática da Universidade do Minho. O trabalho centra-se no desenvolvimento
do **PlastID**, um framework automatizado em MATLAB para deteção, segmentação,
caracterização morfológica e classificação de microplásticos em imagens de
microscopia de fluorescência, no contexto do projeto RESOLVE.
