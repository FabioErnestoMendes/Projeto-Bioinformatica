# Fase 1 — Relatório Intercalar

Esta pasta contém o relatório intercalar submetido no final da primeira
fase do projeto.

## Documento

- `Projeto_Bioinformática.pdf` — Relatório intercalar que descreve a revisão
  bibliográfica inicial, a definição do problema e a metodologia
  preliminar para a deteção automática de microplásticos em imagens
  de microscopia de fluorescência.

## Conteúdo do Relatório

- Enquadramento e motivação para a análise automática de microplásticos
- Revisão de métodos de deteção espetroscópicos e baseados em imagem
- Identificação do gap de investigação abordado neste trabalho
- Descrição preliminar do pipeline proposto em MATLAB
- Objetivos iniciais no contexto do projeto RESOLVE

## Notas

Este relatório representa trabalho em progresso. A metodologia final,
os resultados experimentais e a descrição completa do sistema encontram-se
no artigo principal localizado na pasta raiz deste repositório.
